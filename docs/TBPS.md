# Task Best Practices

TBPs define reusable operational engineering guidance for recurring work in this repository.

TBPs are:
- project-specific
- implementation-oriented
- reusable by humans and agents

TBPs should be referenced:
- in issue templates
- in workflow documentation
- in implementation planning

| TBP | Purpose |
|---|---|
| [`documentation-changes.md`](tbps/documentation-changes.md) | Keep authoritative documentation, indexes, and routing documents synchronized |
| [`workflow-changes.md`](tbps/workflow-changes.md) | Update workflow intent before changing GitHub Actions implementation |
