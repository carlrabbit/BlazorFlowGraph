# TBPs Directory

This directory stores Task Best Practices referenced by [`../TBPS.md`](../TBPS.md).

Use TBPs for repeatable methodology and repository process. Do not use them as the primary source for feature semantics, architecture decisions, or one-off task notes.

Start with the index in [`../TBPS.md`](../TBPS.md), then open the specific TBP for execution steps and validation.

# Authority

This document is authoritative for TBP directory routing and the expectation that `docs/TBPS.md` remains the primary TBP index.

# Document Contract

Update this file when the TBP directory structure or routing guidance changes. Keep it synchronized with [`../TBPS.md`](../TBPS.md).
